# Switcher — умный переключатель раскладки RU/EN

Как Punto Switcher, только учится на вас: запоминает ваши исправления, сам
заводит правила, знает ваши словечки и привычки в каждом приложении, а Claude
периодически разбирает ваши ошибки и описывает ваш стиль письма.

```
ghbd…            →  прив…           (раскладка переключается после 3–4 букв, дальше — уже по-русски)
ghbdtn rfr ltkf  →  привет как дела
руддщ цщкдв      →  hello world
e vtyz           →  у меня          (короткое слово исправляется по соседнему)
превет, teh      →  привет, the     (опечатки)
пРИВЕТ           →  Привет          (случайно включённый Caps Lock)
z pfgeibk d main →  я запушил в main (фраза вперемешку — по горячей клавише с ИИ)
```

## Чем он умнее Punto

| | Punto Switcher | Switcher |
|---|---|---|
| Как решает | словари и сочетания букв | частоты ~1 млн словоформ (RU+EN) + модель букв для незнакомых слов + контекст фразы |
| Когда переключает | после первых букв | тоже после первых 3–4 букв; если слово целиком окажется другим — вернёт как было |
| Короткие слова (`e`, `b`, `c`) | часто мимо | решает по соседним словам и переисправляет задним числом |
| Ваши исправления | нужно вручную добавлять исключения | каждое исправление само становится правилом |
| Ваш сленг и термины | не знает | личный словарь: «коммитнуть», «пушнуть», имена, названия |
| Разные приложения | одинаково везде | помнит, где вы пишете по-русски, а где по-английски; в IDE и терминале осторожнее |
| Опечатки | автозамена по готовому списку | исправляет сам («превет» → «привет», «teh» → «the»): соседние клавиши, переставленные и пропущенные буквы, а/о, е/и; плюс учит ваши типичные опечатки |
| ИИ | нет | Claude разбирает журнал исправлений, предлагает правила и описывает ваш стиль |

## Установка на Windows

1. Скачайте **`SwitcherSetup-….exe`** со страницы
   [Releases](https://github.com/battaloff/Switcher_ENG_RUS/releases) (или из последней
   сборки на вкладке [Actions](https://github.com/battaloff/Switcher_ENG_RUS/actions) → артефакт
   `SwitcherSetup`).
2. Запустите. Права администратора не нужны. Если Windows покажет «Система Windows
   защитила ваш компьютер» — установщик не подписан сертификатом: «Подробнее» →
   «Выполнить в любом случае».
3. Switcher запустится и откроет окно настроек. Дальше он живёт в трее у часов и
   стартует вместе с Windows (галочку можно снять в установщике или в настройках).

Python и командная строка не нужны: всё настраивается в окне (щелчок по значку в трее):
ключ Claude, автозапуск, осторожность, горячие клавиши, исключения, правила и
«что я о вас знаю». Удаляется как обычная программа через «Параметры → Приложения»;
выученный профиль остаётся в `%APPDATA%\Switcher` на случай переустановки.

Чтобы исправлять текст в программах, запущенных от администратора, сам Switcher
тоже нужно запускать от администратора. Windows не пускает обычные программы в такие окна,
поэтому Switcher там ничего не видит и не может печатать. Когда вы открываете такую программу,
он сразу об этом говорит, а «Проверить, всё ли работает» показывает их список.

### Обновление и откат

«Настройки» → **«Обновления»**: список версий с кратким «что нового» у каждой.
**«Обновить»** ставит новую версию, **«Откатить»** — любую прежнюю, если с новой что-то не так.
Switcher скачивает установщик с GitHub, проверяет его контрольную сумму, закрывается на
несколько секунд, тихо переустанавливается и запускается снова; настройки, ключ и всё
выученное остаются на месте. Если установка не удалась, запускается прежняя версия, а
журнал установки лежит в `%LOCALAPPDATA%\Switcher\cache\updates\install.log`.

Список версий берётся из файла `releases.json`, который прикладывается к каждому выпуску:
его отдают серверы загрузок GitHub без ограничения на число запросов (у API — 60 в час
на адрес, и с VPN их часто выбирают другие).

Дважды в день Switcher сам проверяет, нет ли новой версии, и говорит о ней уведомлением
(выключается там же). В меню значка в трее появляется «Обновить до версии …».
Работает начиная с версии 0.2.0; на неё с более ранней сборки нужно один раз перейти вручную.

## Установка из исходников (macOS, Linux, разработка)

Нужен Python 3.10+.

```bash
git clone https://github.com/battaloff/Switcher_ENG_RUS.git
cd Switcher_ENG_RUS
pip install -e ".[gui]"       # [gui] — окно настроек и значок в трее
switcher prepare              # один раз: собрать языковые модели (~20 с)
switcher run                  # или `switcher gui` — с окном настроек
```

Запуск вместе с системой: `switcher autostart on` (выключить — `switcher autostart off`).

**macOS.** Дайте терминалу (или Python) доступ в «Системные настройки →
Конфиденциальность и безопасность → Универсальный доступ» и «Мониторинг ввода».
Поддерживаются раскладки «Русская» и «Русская — ПК» (определяется
автоматически). Значка в меню нет: уведомления приходят через Центр уведомлений.

**Linux.** Нужен сеанс X11 и раскладки `us,ru` (`setxkbmap -layout us,ru`).
В Wayland чужие нажатия клавиш перехватывать нельзя.

`switcher doctor` проверит, всё ли на месте.

### Подключить Claude

ИИ-функции необязательны: без них всё остальное работает, включая обучение на ваших
исправлениях. Чтобы их включить, вставьте ключ API (его выдают на
[console.anthropic.com](https://console.anthropic.com/settings/keys)) в настройках на
вкладке «Claude (ИИ)» и нажмите «Проверить». В Windows ключ хранится зашифрованным
(DPAPI — расшифровать его может только ваша учётная запись). Вместо этого можно задать
переменную окружения `ANTHROPIC_API_KEY`.

По умолчанию используется модель `claude-opus-5-5` (меняется в настройках). Если
модель откажется обработать запрос, API само повторит его на запасной модели
(серверный `fallbacks: "default"`).

## Как пользоваться

| Действие | Клавиши |
|---|---|
| Исправить последнее слово / отменить автоисправление | **Shift дважды** |
| Исправить выделенный текст: раскладку и опечатки | `Shift+Pause` |
| Исправить всю фразу (или выделение) с помощью Claude | `Ctrl+Alt+Space` |
| Пауза / продолжить | `Ctrl+Alt+S` |

Любое сочетание можно поменять: «Настройки» → «Изменить» напротив действия → нажать
нужные клавиши (Ctrl/Alt + клавиша, Shift или Ctrl дважды, Pause, F1–F24) →
«Сохранить». Esc отменяет запись, «✕» выключает сочетание.

Выделенный текст по `Shift+Pause` исправляется сразу: Switcher меняет раскладку только у
слов, набранных не в той раскладке («ыршае=зфгыу» → «shift=pause»), и исправляет опечатки.
Если в тексте осталось то, чего Switcher не знает («RE;liable»), а Claude подключён, текст
исправит Claude — это занимает пару секунд. Текст, который и так правильный
(«shift+pause»), остаётся как есть — нажмите `Shift+Pause` ещё раз, и раскладка всё равно
сменится.

**Дописывание.** В «Настройки» → «Дописывание» задайте, что вы начинаете печатать и во что это
превращать: «015» → «015-510-400_4_». Как только начало набрано отдельным словом, Switcher
допишет остальное; двойной Shift сразу после — вернуть как было. Дописывание работает только
в окнах «Сохранить как» и «Экспорт», то есть для имён файлов: «745», набранное как размер в
CorelDRAW, так и останется. В «Основном» можно включить дописывание везде или выключить
его совсем, не удаляя шаблоны.

**AutoHotkey.** В «Настройки» → «AutoHotkey» собраны ваши скрипты, в том числе уже запущенные
и лежащие в автозагрузке: их можно запускать, останавливать и перезапускать, а нужные —
запускать вместе со Switcher. Те же скрипты есть в меню значка → «AutoHotkey»: галочка стоит
у запущенных, щелчок запускает или останавливает скрипт. Двойной щелчок по скрипту открывает
редактор с подсветкой и номерами строк. Кнопка «Проверить» находит ошибку и показывает её
строку, «Сохранить и перезапустить» применяет правку сразу. Если Claude подключён, ему можно
написать по-русски, что сделать: «Ctrl+Alt+D — вставить сегодняшнюю дату» или «почини ошибку».
Нужен установленный AutoHotkey v1 или v2 ([autohotkey.com](https://www.autohotkey.com/)).
Текст, который печатают ваши скрипты, Switcher не исправляет и не считает вашим набором.
Если скрипт занимает клавиши Switcher (например, `^!s::` — это его Ctrl+Alt+S, или `~Shift::`,
мешающий двойному Shift) или его замена совпадает с шаблоном дописывания, Switcher предупредит:
уведомлением при запуске скрипта, списком на странице «AutoHotkey», подсветкой строки в редакторе
и подсказкой, когда вы назначаете горячую клавишу.

**Клавиши AHK.** В «Настройки» → «Клавиши AHK» собраны все горячие клавиши и замены из ваших
скриптов: какие клавиши, что делают (из комментария или самой команды), в каком скрипте и
строке. «Назначить сочетание…» — нажмите новое сочетание, и Switcher перепишет строку скрипта
(сохранив `~`, `$`, `*`) и перезапустит его. «Добавить…» — новая клавиша без программирования:
напечатать текст, открыть программу, папку или сайт, или одна команда AutoHotkey. Такие
клавиши живут в скрипте «Switcher — клавиши.ahk», который Switcher создаёт и запускает сам.

**Сохранение файлов.** Когда открывается окно «Сохранить как», Switcher переключает раскладку
на английскую — имя файла сразу набирается латиницей (выключается в «Основном»).

Раскладка переключается уже после первых 3–4 букв, как в Punto: «ghbd» станет «прив»,
и остаток слова наберётся по-русски. Когда слово закончено, Switcher проверяет его
целиком и, если догадка оказалась неверной, возвращает как было. Двойной Shift прямо
посреди слова отменяет переключение и запоминает слово.

Опечатки исправляются, когда слово закончено: «превет» → «привет», «спсибо» → «спасибо»,
«Здривствуйте» → «Здравствуйте», «teh» → «the». Не трогаются имена с заглавной буквы посреди предложения, сокращения
заглавными, ваши собственные слова и всё в редакторах кода и терминалах. Двойной Shift
сразу после исправления возвращает ваш вариант — и это слово больше не исправляется.

Автоисправление целых слов срабатывает на пробеле (и Tab). На Enter по умолчанию нет:
в мессенджерах Enter успевает отправить сообщение раньше, чем текст исправится
(включается настройкой `convert_on_enter`).

## Как он учится

Ничего настраивать не нужно — просто исправляйте, как привыкли.

| Что вы делаете | Что он понимает | Что меняется |
|---|---|---|
| Отменили автоисправление (двойной Shift или стёрли слово и набрали заново в прежней раскладке) | «это слово так и должно быть» | правило «не трогать», в этом приложении он становится осторожнее |
| Исправили слово, которое он пропустил (двойной Shift или стёрли и перенабрали в другой раскладке) | «пропустил ошибку» | правило «всегда переключать», в этом приложении он становится смелее |
| Двойной Shift нажали сразу ещё раз | «передумал» | правило отменяется |
| Стёрли первые буквы и перенабрали в другой раскладке | ошибку вы поймали сами | попадает в журнал для разбора ИИ |
| Дважды исправили одну и ту же опечатку («превет» → «привет») | ваша типичная опечатка | правило автозамены (тоже отменяется двойным Shift) |
| Просто пишете | какие слова ваши и на каком языке вы пишете в каждой программе | личный словарь, языковая статистика по приложениям |
| Исправили фразу через Claude | какие слова были набраны не в той раскладке | правила для этих слов |

Каждые 20 исправлений (настраивается) Claude разбирает журнал: предлагает правила,
удаляет ошибочные, настраивает приложения и обновляет описание вашего стиля.
Предложения проверяются перед применением, а ваши ручные правила ИИ не трогает
никогда. Запустить разбор вручную: `switcher learn` (или `switcher learn --dry-run`,
чтобы только посмотреть).

## Команды

```bash
switcher run                  # запустить
switcher stats                # что он о вас узнал: правила, ошибки, языки по приложениям, стиль
switcher explain ghbdtn vs    # почему слово переключается или нет (с оценками)
switcher convert "Ghbdtn? rfr ltkf"          # перевести текст в другую раскладку
switcher rules list
switcher rules add Kubernetes                # всегда оставлять по-английски
switcher rules add коммит                    # всегда по-русски
switcher rules add vs --lang en --app Code   # только в VS Code
switcher rules typo превет привет            # своя автозамена
switcher rules remove vs
switcher learn                # попросить Claude разобрать исправления сейчас
switcher export > profile.json
switcher forget --yes         # стереть всё выученное
```

## Настройки

Файл `config.json` лежит в папке данных (`%APPDATA%\Switcher`,
`~/Library/Application Support/Switcher`, `~/.config/switcher`) и создаётся при
первом запуске. Главное:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `threshold` | `2.0` | насколько вариант в другой раскладке должен быть вероятнее (в порядках частоты), чтобы переключить |
| `look_back` | `true` | переисправлять короткое предыдущее слово |
| `convert_on_enter` | `false` | исправлять ли слово перед Enter |
| `fix_caps_lock` | `true` | «пРИВЕТ» → «Привет» и выключить Caps Lock |
| `fix_two_capitals` | `true` | «ЗДравствуйте» → «Здравствуйте» (двойной Shift вернёт и запомнит слово) |
| `english_in_save_dialogs` | `true` | в окне «Сохранить как» включать английскую раскладку |
| `snippets` | `{}` | дописывание: `{"015": "015-510-400_4_"}` |
| `writes_uzbek` | `false` | не трогать узбекские слова (латиница и кириллица): «олдин», «улар», «bugun» |
| `early_switch` | `true` | переключать раскладку после первых 3–4 букв, как Punto |
| `autocorrect` | `true` | исправлять опечатки: «превет» → «привет» |
| `excluded_apps` | менеджеры паролей | где Switcher ничего не делает и не запоминает |
| `careful_apps`, `careful_extra` | IDE, терминалы, `1.0` | где нужен больший перевес |
| `ru_variant` | `auto` | `pc` («Русская — ПК», Windows/Linux) или `mac` («Русская» на macOS) |
| `hotkeys.*` | см. выше | проще всего назначить в окне настроек: «Изменить» и нажать клавиши. В файле: `double_shift`, `double_ctrl`, `<pause>` или `<ctrl>+<alt>+x`; пусто — выключено |
| `learning.typo_min_repeats` | `2` | сколько раз исправить опечатку, чтобы появилось правило |
| `ai.enabled`, `ai.model` | `true`, `claude-opus-5-5` | ИИ-функции |
| `ai.review_every` | `20` | исправлений между разборами (0 — только вручную) |
| `ai.fix_typos` | `false` | разрешить ИИ при исправлении фразы править и опечатки |

## Точность

Замер `python tools/evaluate.py` (слова, набранные в правильной раскладке, и они же — в
неправильной):

| | ложные переключения | пропуски |
|---|---|---|
| частые слова (с учётом частоты) | 0.01 % | 0.7 % для слов от 4 букв; однобуквенные решаются по соседним словам |
| незнакомые словарю слова | 1.2 % (в основном 2–3-буквенные сокращения) | 6 % |

Переключение по первым буквам (`python tools/evaluate_early.py`): ни одного ложного
срабатывания на 40 000 частых слов и 0.03 % на незнакомых словарю; слова в неправильной
раскладке переключаются к 3-й букве в 51 % случаев, к 4-й — в 86 %.

Опечатки (`python tools/evaluate_spelling.py`): исправляется 72 % типичных опечаток
в одну букву; правильно написанные частые слова меняются в 0.03 % случаев (редкие
настоящие слова — после отмены двойным Shift они защищены навсегда).

Всё, что осталось, доучивается на ваших исправлениях.

## Приватность

- Всё выученное хранится локально в `profile.sqlite3`; посмотреть — `switcher stats`
  или `switcher export`, стереть — `switcher forget --yes`.
- Полный поток нажатий нигде не сохраняется. В журнал попадают только слова, которые
  исправляли вы или программа, и спорные случаи; в личный словарь — редкие слова,
  которых нет среди частых в словаре.
- Claude получает только журнал исправлений, правила, статистику по приложениям и
  личный словарь (при разборе) или конкретную фразу (когда вы сами жмёте ИИ-исправление).
- В менеджерах паролей (`excluded_apps`) Switcher ничего не делает и не запоминает.
  Надёжно отличить поле пароля в любой программе нельзя, поэтому пароли, набранные
  в обычных программах, могут оказаться в журнале, если программа их исправит.

## Состояние

Что менялось от версии к версии — в [CHANGELOG.md](CHANGELOG.md). Каждое изменение проверяется на Windows-машине GitHub
([workflow](.github/workflows/windows.yml)): тесты (движок, обучение, ИИ, окно
настроек, шифрование ключа), сборка установщика, самопроверка собранного
`Switcher.exe`, тихая установка → запуск → обновление поверх → удаление и сквозной сценарий в Блокноте —
программа перехватывает настоящие нажатия, переключает раскладку и исправляет текст.
В Linux/X11 то же проверяется на виртуальном X-сервере (`tools/x11_smoke.py`).
Код для macOS написан по API, но на живой системе ещё не запускался.

Если что-то пошло не так, пришлите `switcher.log` из папки данных
(`%APPDATA%\Switcher`).

## Как выпустить новую версию

1. Поднимите `__version__` в `switcher/__init__.py` (например, `0.2.1`).
2. Добавьте в [CHANGELOG.md](CHANGELOG.md) раздел `## 0.2.1 — дата` с пунктами
   «Новое: …» / «Исправлено: …» — их пользователь увидит на странице «Обновления».
3. Закоммитьте и отправьте в основную ветку репозитория — больше ничего не нужно.

GitHub Actions соберёт и проверит установщик на Windows (включая обновление поверх
установленной версии) и, если все проверки прошли, сам опубликует выпуск с этим
описанием. Запущенный Switcher проверяет новые версии каждые три часа и пишет «Вышла
версия …» — остаётся нажать «Обновить» в «Настройки» → «Обновления». Коммиты без новой
версии только собираются и проверяются. Если в CHANGELOG нет раздела для версии или
хоть одна проверка не прошла, выпуск не состоится.

Выпустить вручную тоже можно: **Actions → Windows installer → Run workflow** с отметкой
«Опубликовать выпуск» (из любой ветки) или тегом `git push origin v0.2.1`.

## Как устроено

```
switcher/
  layouts.py     физические клавиши ⇄ символы QWERTY и ЙЦУКЕН (ПК и Mac)
  langmodel.py   словарь частот (wordfreq, ~1 млн словоформ) + 4-граммная модель букв
  engine.py      решение по слову: две трактовки, правила, контекст, пороги
  controller.py  отслеживание набора, исправление, отмена, горячие клавиши, распознавание ваших правок
  learner.py     исправления → правила, личный словарь, пороги по приложениям
  speller.py     исправление опечаток: кандидаты в одну правку, цена ошибки по клавиатуре и звучанию
  profile.py     локальный профиль (SQLite)
  ai.py          Claude: разбор журнала и исправление фраз (structured outputs)
  platform/      Windows (WinAPI), macOS (Text Input Sources), Linux (XKB)
  gui.py         окно настроек; gui_main.py — точка входа Switcher.exe
  updater.py     обновление и откат: версии с GitHub Releases, проверка файла, тихая переустановка
  secrets.py     шифрование ключа Claude (Windows DPAPI)
  app.py, cli.py, tray.py, autostart.py, report.py
packaging/windows/
  build.py       модель → Switcher.exe (PyInstaller) → самопроверка → установщик (Inno Setup)
tools/
  evaluate.py        замер точности
  x11_smoke.py       сквозная проверка на виртуальном X-сервере
  windows_smoke.py   сквозная проверка в Блокноте Windows
  windows_update_smoke.py  обновление поверх установленной версии
  release_notes.py   описание выпуска из CHANGELOG.md
  release_manifest.py  releases.json — список версий для программы
  evaluate_early.py  замер переключения по первым буквам
  evaluate_spelling.py  замер исправления опечаток
  gui_screenshots.py снимки всех страниц настроек
```

Тесты: `pip install -e ".[dev]" && pytest`.
Сквозная проверка: `xvfb-run -a python tools/x11_smoke.py`.
