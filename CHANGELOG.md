# Что нового в Switcher

Каждый раздел — одна версия. Его пункты попадают в описание выпуска на GitHub, и именно их
Switcher показывает в «Настройки» → «Обновления» рядом с кнопками «Обновить» и «Откатить».
Пишите коротко, по пункту на изменение, начиная с «Новое:» или «Исправлено:».

## 0.3.2 — 30.09.2026

- Исправлено: Shift+Pause исправляет выделенное сразу — Claude нужен только там, где Switcher не справится сам («RE;liable»)
- Исправлено: слова через «=», «+» или цифры исправляются по отдельности: «ыршае=зфгыу» → «shift=pause», «d 10^30» → «в 10:30»
- Исправлено: с моделью claude-haiku-4-5 (самой быстрой) исправление через Claude больше не падает с ошибкой

## 0.3.1 — 30.09.2026

- Исправлено: Windows иногда незаметно отключает программу от клавиатуры — теперь Switcher это замечает и подключается снова
- Исправлено: в полях, где слово заканчивают Enter (переименование папки, поиск), и во фразах заглавными короткое слово тоже исправляется: «YF VFIBYF» → «НА МАШИНАХ»
- Исправлено: опечатка в гласной в длинном слове: «Здривствуйте» → «Здравствуйте»
- Исправлено: если раскладку только что переключили вручную и не ту, слово всё равно исправляется по первым буквам
- Новое: Shift+Pause исправляет выделенный текст, как в Punto: с Claude — вместе с опечатками («RE;liable» → «Reliable»)
- Исправлено: выделенный правильный текст больше не портится («shift+pause» → «ыршае+зфгыу»); повторное нажатие меняет раскладку
